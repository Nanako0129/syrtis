## Features

- **Grok Bot usage moves from the Cursor tab to the Grok Build & Bot tab.** [#499](https://github.com/Nanako0129/syrtis/pull/499)

  Cursor's usage records for Grok Bot models (model names starting with `grok-bot`) now count as Grok Bot instead of Cursor. Totals across all clients don't change.

  Hiding the Cursor tab no longer hides this usage; hiding the Grok Build & Bot tab does. In usage attribution, Grok Bot's rows are suggested for Grok Bot's own plan. If you had assigned Cursor's xAI usage to Grok Bot by hand, check that choice: it now applies only to Cursor's own Grok-model usage.

- **The main Antigravity card reads a captured account's quota instead of running agy.** [#502](https://github.com/Nanako0129/syrtis/pull/502)

  When Syrtis knows which captured account agy is signed into, because "Capture accounts agy signs into automatically" captured it or you pressed "Capture current agy login", the main card now reads that account's quota through its captured sign-in. Its source label reads OAUTH, and the account shows as one card.

  Syrtis checks agy's sign-in before and after reading. If agy has signed in again or switched accounts, that round runs agy as before and the label reads AGY. With automatic capture off, a Capture works this way only until agy next refreshes its sign-in; the hint under the switch in Settings → General → Antigravity accounts now says so. Without a captured account, nothing changes.

## Fixes

- **Rotating, panning or zooming the 3D chart could stutter.** [#498](https://github.com/Nanako0129/syrtis/pull/498)

  The camera position was saved on every movement. It's now saved once you stop.

- **Dragging the Glass tint slider could stutter.** [#500](https://github.com/Nanako0129/syrtis/pull/500)

  Same cause: the setting was saved on every step. It's now saved once you stop dragging.

- **A limits card with an error showed empty "No data" rows under the red message.** [#501](https://github.com/Nanako0129/syrtis/pull/501)

  When a card has an error and no quota windows, it now shows just the error.
