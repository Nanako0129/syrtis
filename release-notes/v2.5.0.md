## Features

- **Cursor usage without the tokscale CLI.** [#487](https://github.com/Nanako0129/syrtis/pull/487), [#488](https://github.com/Nanako0129/syrtis/pull/488)

  Syrtis now downloads your Cursor usage itself, using the login of the Cursor app on this Mac. Before, Cursor usage appeared only after the tokscale CLI had synced it.

  The first time, a card on the Overview asks before anything is read; it appears only if Cursor is installed. After Continue, Syrtis syncs at launch and every 30 minutes. Settings → General → Cursor usage sync has the switch, the last sync time, and Sync Now.

  The login is sent only to Cursor's usage service (cursor.com) and is never saved or logged. Syrtis stores the date, model, token counts, cost and conversation ID of each request on this Mac. Turning the switch off deletes the downloaded usage.

  If the tokscale CLI already keeps Cursor data on this Mac, Syrtis keeps showing that data, and Settings asks whether to use Syrtis's own sync instead. Choose it only for the same Cursor account; either way the usage is counted once.

  Cursor's login expires when the app has not run for a while. Sync then pauses and Settings says so until Cursor is opened again. Grok Bot usage billed to a Cursor account appears under Cursor.

## Fixes

- **Cursor usage was missing when a recent tokscale CLI had synced it.** [#487](https://github.com/Nanako0129/syrtis/pull/487) — thanks [@whes1015](https://github.com/whes1015)

  Recent tokscale CLIs save Cursor usage as `usage.json`, which Syrtis did not read; it read only the older `usage.csv`. Syrtis now reads both.
